# 다음 작업

2026-09-21 기준. 모델과 학습 운영 코드를 구현하고 짧은 실제 실행을 확인했다. 다음 단계는 데이터 보강과 본학습이다.

1. **학습 자료 정리**
   추가 신호등과 차선 원본을 sources에 등록한다. 모든 램프가 off인 표본의 처리 방식을 정하고, 촬영 구간이 학습과 평가에 섞이는지 확인한다.
2. **신호등 기준선 학습**
   차량용과 보행자용 검출, SignalAttr의 상태별 오탐과 미탐을 평가한다. 원형 초록과 좌회전의 혼동, 판독 유효 비율을 함께 확인한다.
3. **도로표식과 공동학습**
   흰 차선, 노란 차선, 정지선의 최종 점열을 평가한다. 연결 끊김이나 선 합쳐짐이 남으면 출력 예시를 보고 디코더와 후처리를 조정한다.
4. **실행 성능**
   [추론 처리시간](8_INFERENCE_PERFORMANCE.md)의 병목을 기준으로 학습된 가중치의 점열 개수와 지연시간을 다시 잰다. 같은 확률맵을 사용하는 C++ 점열 후처리의 출력과 속도를 비교하고 TensorRT 엔진의 계산 및 전송 시간을 측정한다. 후단 및 20Hz LiDAR와 함께 실행해 좌우 전체 처리시간과 출력 속도를 확인한다.

현재 기본값과 명령은 [실행 안내](7_RUN_GUIDE.md)에 있다. 구현 진척은 [현재 상태](00A_CURRENT_STATUS.md), 학습 방법은 [학습과 평가](6_TRAINING_AND_EVALUATION.md)를 따른다.
