# 추론 처리시간

2026-09-21 소규모 학습 체크포인트의 진단 결과다. 본체와 SignalAttr의 학습 결과 및 평가 범위는 [현재 상태](00A_CURRENT_STATUS.md)에 있다. 현재 출력은 도로표식 오탐이 많아 이 측정값을 최종 배포 속도로 사용할 수 없다.

## 측정 조건

RTX 4060 Laptop 8GB에서 PyTorch 모델과 Python 후처리를 실행했다. AIHub 검증 영상 두 장을 800×600 RGB로 준비해 좌우 카메라 입력 크기를 모사했고, 모델 입력은 여백을 포함한 800×608이다. `OMP_NUM_THREADS=1`, `MKL_NUM_THREADS=1`로 실행했다. 영상 파일 로드와 800×600 준비, 체크포인트 로드는 처리시간에서 제외했다. 측정 구간은 영상 letterbox부터 GPU 모델 계산, 신호등 상태 판독, 최종 점열 생성까지이며 GPU 동기화 후 종료했다. ROS, LiDAR, TensorRT는 실행하지 않았다.

사용한 가중치와 추론 예시는 외장 SSD의 `/home/user1/Storage/ROS2_Workspace_offload/yolopv26/20260921_small_full_run/`에 있다. [추론 명령](../tools/predict_pv26.py)은 모델과 이미지 파일을 먼저 읽고 `pipeline.predict()`만 시간을 잰다. 이전에 보고한 약 496ms도 모델 파일을 여는 시간은 포함하지 않은 첫 추론이었다.

## 측정 결과

| 영상 두 장, 같은 프로세스 | 첫 호출 | 예열 후 8회 중앙값 | 예열 후 8회 최댓값 | 출력 개수 |
| --- | ---: | ---: | ---: | --- |
| 검출 confidence 0.01 | 508ms | 115ms | 187ms | 신호등 박스 11개, 도로표식 점열 680개 |
| 검출 confidence 0.25 | 앞선 실행으로 GPU가 예열된 상태 | 102ms | 175ms | 신호등 박스 1개, 도로표식 점열 680개 |

confidence 0.25가 현재 추론 명령의 기본값이다. confidence 0.01은 신호등 검출 결과와 SignalAttr의 연결을 확인할 때 사용했다. 두 설정에서 도로표식 출력량은 같다. 위 최댓값은 표본 8회 중 최대값이며 p95 측정값이 아니다.

confidence 0.01 조건에서 단계를 따로 동기화해 잰 예열 후 중앙값은 영상 전처리 5.1ms, GPU 입력 전송 3.1ms, 본체 모델 계산 16.7ms, 신호등 박스 복원 0.3ms, 도로표식 점열 후처리 72.3ms, SignalAttr 6.1ms였다. 첫 호출의 본체 계산은 약 347ms였다. 단계별 시간을 합친 값과 전체 `predict()` 시간은 동기화 방식과 실행 중 변동 때문에 같지 않다.

가장 큰 반복 비용은 [도로표식 후처리](../model/engine/postprocess.py)다. 확률맵을 CPU로 옮긴 뒤 행 또는 열마다 후보 정점을 찾고 Python에서 점열을 연결한다. 현재 체크포인트는 실제 도로와 무관한 곳에도 많은 점열을 출력한다. 후보를 처리하는 시간이 출력 밀도에 따라 커진다.

현재 목표인 좌우 20Hz는 두 장당 50ms, 하한 10Hz는 100ms, 후단 계산 여유를 위한 희망치는 33ms 미만이다. 측정한 PyTorch 경로는 이 조건을 안정적으로 만족하지 못한다.

## 다음 최적화 순서

1. 신호등과 도로표식의 검출 품질을 먼저 확보하고 실제 점열 개수와 전체 지연시간을 여러 장면에서 다시 잰다. 후처리 시간이 출력 밀도에 얼마나 좌우되는지 확인한다.
2. 현재 점열의 좌표와 연결 결과를 기준으로 C++ 후처리를 구현해 같은 확률맵에서 처리시간과 출력 차이를 측정한다. 후보가 많은 장면에서도 측정한다. C++로 옮겨도 후보 수와 GPU 출력 복사 비용은 남는다.
3. 학습된 본체를 TensorRT 엔진으로 변환해 PyTorch와 출력을 비교하고 GPU 계산, 입력 전송, 출력 전송, 전체 지연시간을 각각 잰다. 현재 TorchScript 파일은 TensorRT 엔진이 아니다. [NVIDIA TensorRT 측정 문서](https://docs.nvidia.com/deeplearning/tensorrt/latest/performance/benchmarking.html)는 GPU 계산과 전송 시간을 구분한다.
4. 최종 좌우 카메라 입력, 후단 모듈과 20Hz LiDAR가 함께 실행되는 환경에서 처리시간 분포와 실제 출력 주기를 확인한다.

현재 분해 측정에서는 도로표식 후처리를 제외한 단계만 합쳐도 약 31ms다. TensorRT와 C++의 절감량을 실제로 재기 전에는 33ms 달성 여부를 예측할 수 없다.
